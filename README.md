# 아고라 서구

정책을 시행하기 전에, 공공데이터로 만든 가상 주민들에게 먼저 반응을 물어보는 AI 서비스의 소개(랜딩) 페이지입니다.

- 공개 주소: https://agora-seogu.vercel.app
- 예비 주소: https://solita91081-cpu.github.io/agora-seogu/

## 구성

`index.html` 파일 하나로 동작합니다. 내려받아 더블클릭하면 브라우저에서 바로 열립니다.
별도 설치나 빌드 과정이 필요 없습니다.

- 인트로: 가상의 지역화폐 개편안을 만난 6명의 하루
- 문제 / 작동 방식 / 가상 주민 / 시연 / 신뢰 / 확장 가능성 / 추진 계획

## 안내

등장 인물은 모두 공공 통계를 바탕으로 한 가상 인물이며, 인트로와 시연의 정책안·수치·반응은
설명을 위한 예시 시나리오입니다. 실제 주민 의견수렴을 대체하지 않고 보완하는 도구입니다.

기획: 대전 서구청 기획예산과 · AI 실습 과제
